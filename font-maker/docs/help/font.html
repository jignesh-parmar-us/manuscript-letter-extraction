Using your font

Font Maker builds a TrueType font (.ttf) from a book's letter groups. Typing Devanagari in it shows the book's own letters. Gujarati typing is not changed: programs show their normal Gujarati font for it.

1. Download it

  1. Open the font in Font Maker, tab Build, and press Build font (or Build again after a change).
  2. Click Download. The file is called like the font, with the build number: Vachnamrut-1944-3.ttf.

2. Install it on the Mac

  1. Double-click the .ttf file. Font Book opens.
  2. Click Install. The font now shows in every program's font list under its name.
  3. Quit and open Word or Pages again if it was open, so it sees the new font.

3. After a new build

  1. In Font Book, find the font, select it and choose File → Remove (or press Delete).
  2. Install the new .ttf as above, and open Word or Pages again.

Every build has a new version number (Version 1.001, 1.002, …), so the Mac does not keep showing the older one. If an old shape still shows, remove every copy of the font in Font Book and install the new file again.

4. Use it in Word and Pages

  • Choose the font by its name in the font list, then type Devanagari (for example with the Mac's Devanagari – QWERTY or Hindi – Transliteration keyboard).
  • Text you paste keeps its own font; select it and choose this font.
  • Send the document to someone who does not have the font: Word → Preferences → Save → Embed fonts in the file. The font may be embedded. Or save as PDF: the font is always inside the PDF.

5. One even headline

Each akshara of the book was cut on its own, so its headline sits a little higher or lower than its neighbour's. With Even the headline (Build tab, on) every glyph's headline is drawn at the same height and thickness, so a word has one straight line. Gaps in the headline stay (they tell भ from म, थ from प, ध from घ). A glyph that looks wrong with it can be left as printed: Glyphs tab → the glyph → Even this glyph's headline. Build again to see the change.

6. Try it: write and download

  • Letters palette next to the text box (under it on a narrow window): click a key to type it at the cursor, as in the reading app's Letters. Keys: In the font draws the keys in your font, Unicode in the normal Devanagari font; either way the text box is in your font. Colours: plain = the book's own, dotted line = pieced together, yellow = filled, red = missing. Hide letters gives the text the whole width; Show letters brings it back. ⌫ letter removes one character, ⌫ akshara the whole akshara (कि at once).
  • Book's aksharas (second page of the palette): every akshara the book printed, by first letter, or found with the search box. A key types the same characters as the single keys would (कि = क + ि), so the text is the same either way.
  • Under the box, one line: ✓ all the book's own, or the aksharas that are not, with the reason; click one to select it in the box.
  • Download the text in the font: Image (.png) and PDF are drawn from the font itself and open anywhere without it (the PDF's text cannot be searched or copied); Text (.txt) is the plain text; Word (.docx) has the font embedded, so it shows on a Mac without the font in Word 16.17 or newer (else install the font).
  • Save as test text: after every build, the Build tab shows how much of each test text is the book's own, with the build before. The book's hand-checked lines are always there.

7. What you may see

You seeMeaningWhat to do
A boxThe book has no letter for this character (missing). Build tab → Fill, then build again. Or find the letter in the book, label it in the reading app, and build again.
A letter with a line under itFilled from a normal Devanagari font (Noto Serif Devanagari), not the book's. It looks thinner than the book's print. Keep it, or turn the line off (Build tab → Mark filled characters) for a clean font.
A conjunct shown with a halant (ख्‌र instead of ख्र)The book has no group for that conjunct, so it is pieced together from single letters (the Try it tab marks it with a dotted line).Find it in the book and label it in the reading app, then build again.
Letters from another fontNot Devanagari (Latin, Gujarati, punctuation): this font does not have them, so the program uses another font.Nothing: this is expected.
