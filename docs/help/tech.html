How it works

The technical route from page images to text: which algorithm runs at each step, how it scores and decides, what images it works on and what is stored. Every value named here is a setting with its default (config.py); a book can change its own settings.

Where things are kept

Everything is in the library folder: one database (library.db, SQLite) and one folder per book.
